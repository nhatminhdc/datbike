# Sài Thành

Website tĩnh của Sài Thành, đại lý ủy quyền Dat Bike. `index.html` nằm ở thư mục gốc, kèm CSS, JS và ảnh. Không cần bước build.

## Deploy trên Vercel

1. Vào [Vercel](https://vercel.com) → **Add New** → **Project**.
2. **Import** repository này.
3. **Framework Preset** chọn **Other**.
4. Để trống **Build Command** (không chạy lệnh build). Output là thư mục gốc.
5. Bấm **Deploy**.

`vercel.json` bật `cleanUrls` để địa chỉ không cần đuôi `.html` (ví dụ `/gioi-thieu`).
